# Dhubri Pilot — Last-Mile Maternal Emergency Response System

**Status:** Concept / Discovery — pre-build
**Repository:** nagakarthijk/sauramandala-report
**Location:** This is a separate project from the Doorstep Incubation Protocol (`/PROTOCOL.md`, root `.html` files). It lives entirely inside this `dhubri-pilot/` folder so the two don't get tangled.

## What this is

A coordination layer for high-risk pregnancy (HRP) and maternal emergencies on the river chars (unconnected river islands) of Dhubri, Assam — where the nearest health facility is only reachable by boat. Today, when an emergency happens, a frontline health worker (ASHA/Anganwadi/ANM) or family scrambles informally to find a boatman, and the receiving facility has no warning and no patient details when the boat arrives. This project builds the digital coordination layer — on top of Glific (WhatsApp-based conversational platform) — to replace that ad-hoc scramble with a triggered, tracked, multi-party flow: **frontline worker → boatman directory → facility → 108/CNES ambulance boat → dashboard.**

- [`whatsapp-journey.json`](./whatsapp-journey.json) + [`whatsapp-journey.html`](./whatsapp-journey.html) — **eight** complete case-to-facility journeys using real WhatsApp Cloud API / Gupshup message JSON shapes, every message's exact payload inspectable via a "raw WhatsApp JSON" toggle. This is the one to show the team. Open `whatsapp-journey.html` and pick SCN-08.
- [`game/`](./game/) — **live multiplayer training exercise**: real people play the actual roles (worker, 2 boatmen, facility) on their own phones in the same room, peer-to-peer, no server. The scenario/outcome engine is thoroughly unit-tested (`node game/game-engine.test.js`, 59 assertions); the real device-to-device networking has **not** been live-tested (this sandbox's network policy blocks the PeerJS CDN/broker outright — do a quick two-device test yourself before running a group session). See `game/README.md`. **Still pre-blueprint.**
- [`glific-flows/`](./glific-flows/) — **real Glific-native flow JSON**, importable into an actual Glific workspace and runnable with Glific's own built-in Simulator (not a custom viewer). `FLOW-W1.json` (single-button Worker Report, now including a Google Sheets char→facility lookup), `FLOW-B1.json` (Boatman Broadcast & Accept), and `FLOW-BRC1.json` (Block Referral Coordinator Alert) — corrected against the team's own real, live-instance-tested Glific notes (`spec_version` 14.3.0, real `send_interactive_msg` quick-reply buttons instead of a guessed `quick_replies` field, the confirmed-broken `router.wait.timeout` removed, corrected `@results.*` variable syntax), and structurally validated (`validate-flow.js` — every exit/category/case cross-reference checked, no dangling links, no duplicate UUIDs, no malformed UUIDs, no dead timeout keys).
