Glific (WhatsApp)

Glific credentials are NOT stored in this app. They go into your n8n workflows only.

1.Sign up at glific.org (free for NGOs in India)
2.Get your Glific API key from Settings → Access Token
3.Import n8n-workflows.json into your n8n instance
4.Replace YOUR_GLIFIC_URL and YOUR_GLIFIC_API_KEY in each workflow
5.Activate the workflows in n8n

Download the n8n workflow file: n8n-workflows.json

Supabase Schema Setup

One-time setup: run the SQL file in your Supabase SQL Editor.

1.Open your Supabase project → SQL Editor
2.Copy and run the contents of oesn-schema.sql
3.Enable Email OTP in Supabase → Auth → Providers → Email
4.Set the Site URL to your GitHub Pages URL in Auth → URL Configuration

Download the schema file: oesn-schema.sql
